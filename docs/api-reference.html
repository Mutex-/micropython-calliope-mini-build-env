Read this first

The Calliope port changed the pin table but kept parts of the micro:bit's setup. Everything here was checked on a Calliope mini v1 on 25 Nov 2026. The green cards are bugs fixed in this build; the stock firmware still has them.

Breaks code

Import calliopemini

There is no microbit module, so import microbit raises ImportError. To keep micro:bit code working, use import calliopemini as microbit. The REPL already runs from calliopemini import *.

AttributeError

Only pin1 and pin2 are touch pins

pin0 is digital only on this port, so pin0.is_touched() fails. Use pin1 or pin2.

Wrong pins

SPI defaults sit on the LED rows

The defaults pin13, pin14 and pin15 drive the matrix rows. Pass sclk=, mosi= and miso= explicitly, or turn the display off first.

Silent

audio and speech play on pad P0

Both default to pin0, so you hear nothing without an external speaker. For the onboard speaker, call pin_M_SLEEP.write_digital(1) and pass pin=pin_M_IN1 to audio.play(). speech has no pin argument.

Fixed in this build

Accelerometer and compass

The Calliope's Bosch BMX055 now has a driver, so readings, gestures and the compass work. The stock firmware has no driver and stops with panic 50 or 51 on the first read.

Fixed in this build

pin3 is usable

It's an analog pin on the microphone's GPIO and reads the same as pin_MIC. The stock firmware locks it in display mode and raises ValueError.

Fixed in this build

pin16 and pin17 analog reads

read_analog() works on P0.26 and P0.27. On the stock firmware it freezes the board, because mbed's ADC table stops at P0.6.

Fixed in this build

I2C on the Calliope's pins

The bus defaults to pin20 (SDA) and pin19 (SCL), where the onboard sensors are, so i2c.scan() finds 0x10, 0x18 and 0x68 without arguments. That also frees pin0 and pin_M_IN2. The stock firmware uses the micro:bit's P0.30/P0.0.

Fixed in this build

music plays on the speaker

music.play() and music.pitch() default to the onboard speaker and wake the motor driver only while sound plays. Pass pin=pin0 for pad P0. The stock firmware plays on pad P0.

New in this build

gyroscope

Rotation rates from the BMX055's gyroscope, in degrees per second. See gyroscope.

Pin map calliopemini.pin*

Python name, the nRF51 GPIO it drives, and which methods it has. Digital pins have read/write digital, write_analog (PWM) and pull settings. Analog adds read_analog(), and touch adds is_touched() on top of that.
